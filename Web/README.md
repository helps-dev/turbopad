# TurboPad UI

Interactive visual prototype for TurboPad, a meme and RWA launchpad terminal.

## Open in Codex on macOS

1. Extract `turbopad-codex.zip`.
2. Open the Codex/ChatGPT desktop app and choose **Open folder**.
3. Select the extracted `turbopad` folder.
4. Ask Codex to continue from the existing files.

## Preview locally

The current prototype is a static site. Open `dist/index.html` in a browser, or run:

```bash
cd turbopad/dist
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Current scope

- Turbo Score and market discovery
- Turbo Radar signals
- Meme Battles
- Creator Revenue presentation
- Multi-launchpad labels
- RWA market cards
- Responsive desktop and mobile interface

Wallet connectivity, blockchain contracts, live market data, bonding curves, and the RWA backend are not yet connected.
